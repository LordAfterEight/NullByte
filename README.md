# NullByte
NullByte is an exmersive device management and resource mining game set in an unknown environment.

All the game provides you with is control panels, small visual cues and atmospherics in form of audio.

Mine Bits, process them into Bytes, create more devices, write automation scripts, defend against viruses, try to reach a high net worth.
This is the basic game loop. However, you will notice that there are more things to discover...
